# IPD Backend — 전시용 소스

장소·메뉴·리뷰, 커뮤니티, 쿠폰, 지도와 장치 연동 기능의 구조를 소개하는 Kotlin/Spring Boot 포트폴리오입니다. 소스 열람을 위한 저장소이며 빌드·실행·배포용 배포판이 아닙니다.

## 코드 둘러보기

기본 경로는 `src/main/kotlin/com/example/Ipd`입니다.

| 경로 | 구현 내용 |
| --- | --- |
| `user`, `jwt`, `config` | 회원가입·로그인, JWT 인증, 요청별 권한 설정 |
| `place`, `menu`, `review`, `gcoo` | 장소·메뉴·리뷰·모빌리티 데이터 처리 |
| `community` | 게시글·댓글·좋아요 |
| `coupon`, `scheduling` | 쿠폰 발급·만료와 예약 작업 |
| `naver` | 경로 및 주소 API 연동 구조 |
| `qr`, `led` | QR 기반 장치 명령과 LED 제어 구조 |
| `src/test` | 기존 테스트 설계 예제. 전시본에서는 실행하지 않았습니다. |

각 기능은 대체로 Controller → Service → Repository → Domain 순서로 읽을 수 있습니다.

## 전시용으로 정리한 부분

- DB 계정, JWT 서명키, 지도 API 자격증명은 `${VARIABLE}` 참조만 남겼습니다. `.env.example`에는 빈 값과 공개용 예시만 있습니다.
- DB 예시는 로컬 주소이며, 외부 API·이미지 URL과 MQTT 호스트는 `example.invalid` 예시를 사용합니다. 실제 서버·장치·사용자 데이터는 포함하지 않습니다.
- 요청 DTO, 좌표, 토큰, 장치 식별자, MQTT 메시지 및 상세 예외를 출력하던 로그를 제거했습니다. 남은 실패 로그는 고정 문구만 기록합니다.
- 회원가입 요청에서 역할 필드를 제거하고 서버가 `USER`만 부여하도록 했습니다. OWNER/ADMIN 관리 코드는 구조 설명을 위해 남아 있으며 권한 부여 기능은 제공하지 않습니다.
- 지도 프록시는 인증이 필요하고, `/qr/**`, `/led/**`, `/test` 요청은 전시본에서 차단합니다. MQTT는 기본 비활성화이며 비활성 상태의 전송 요청은 실패합니다.
- SQL 출력과 자동 스키마 변경을 껐습니다. 화면·테스트의 전화번호, 주소, 좌표, 이메일과 장치 ID는 전시용 예시입니다.
- 이전 저장소의 Git 기록, CI 배포 설정, IDE/AI 편집기 설정, 업로드·로그·덤프는 이 저장소에 옮기지 않았습니다.

`.env.example`은 설정 항목 설명용입니다. Spring Boot가 `.env`를 자동으로 불러오는 설정은 포함하지 않으며, 실행 환경의 변수를 참조하는 형태만 보여줍니다. 필수 설정은 비어 있으므로 그대로 실행할 수 있다고 가정하면 안 됩니다. [Spring Boot 외부 설정 문서](https://docs.spring.io/spring-boot/3.5/reference/features/external-config.html)

## 구현의 한계

이 코드는 운영 보안이 완성된 서비스 예제가 아닙니다. 전시용 정리는 비밀값·개인정보의 공개 방지와 일부 명확한 위험 경로 차단에 초점을 맞췄습니다.

업로드 서비스는 원래 구현을 보존했으며 확장자 검사만으로 안전한 이미지를 보장하지 않습니다. 실제 사용에는 파일 내용 디코딩, 용량·해상도 제한, 격리 저장과 접근 제어가 필요합니다. 메뉴·쿠폰 등 객체별 소유권 검사, 계정 입력 검증과 가입 제한, 지도 API 호출 제한, QR 입력 검증과 재전송 방지, MQTT TLS·인증·topic ACL도 운영 수준의 검증 대상입니다.

테스트 소스와 의존성 선언은 구현 참고용입니다. 이 전시본의 빌드, 테스트 통과, 최신 의존성 취약점 점검 또는 실제 장치 동작을 보장하지 않습니다. 실제 서버·DB·장치와 연결하지 마세요.

## 소스 공개 항목 검사

`ruby scripts/check-public-source.rb`는 공개 금지 파일, 환경변수 예시, 민감 로그와 핵심 전시 설정을 검사합니다. 빌드·서비스 실행·외부 API 호출은 하지 않습니다. Git 과거 기록의 secret 검사는 이 스크립트와 별도로 수행해야 합니다.
